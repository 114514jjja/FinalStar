终星 FinalStar v0.28

Degrees of Lewdity 0.5.12.13 中文模组源码。

这是可读源码，不是可直接安装的模组包。安装包请下载 Releases 里的 FinalStar-v0.28.mod.zip。

环境

Degrees of Lewdity 0.5.12.13
ModLoader 2.101.1
Maplebirch Framework 4.1.11
Lyra 中文环境

目录

boot.json 是 ModLoader 清单和 TweeReplacer 补丁。
fs-*.js 是模组运行时代码。
twee/ 是模组段落与控件。
css/ 是界面样式。
img/ 是图标与图片资源。
*.txt 是 TweeReplacer 的替换片段。
tools/ 是打包与静态检查脚本。

构建

python3 tools/check_mod.py --game /path/to/game
python3 tools/pack.py

pack.py 会在 dist/ 生成 FinalStar-v0.28.mod.zip。

安装

1. 先安装 DoL 0.5.12.13、ModLoader、Maplebirch。
2. 游戏内 Mod 管理器选择 FinalStar-v0.28.mod.zip。
3. 导入后立即重载。
4. 旧档请先导出备份。

说明

本模组为成人向虚构内容，仅面向 18 岁以上玩家。
所有角色均为成年人。
请勿将模组用于商业用途或二次售卖。
